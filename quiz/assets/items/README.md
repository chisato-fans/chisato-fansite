# アイテムイラスト素材 仕様書

ガチャで獲得する24種類のアイテムイラストの仕様です。
できあがったファイルをこのフォルダ(`assets/items/`)に置き、
`js/data/item-data.js` の該当アイテムの `image` に
`"assets/items/item01.png"` のようにパスを指定すると、
絵文字の仮アイコンから自動的に切り替わります(コード変更不要)。

## ファイル仕様(共通)

| 項目 | 内容 |
|---|---|
| 形式 | PNG(背景透過) |
| キャンバスサイズ | **600 × 600px**(正方形) |
| 解像度 | 72dpi で構いません(スマホ表示+ Canvas書き出しを想定した実寸指定です) |
| 余白 | 上下左右に約10%の余白を残し、被写体はキャンバスの中央80%程度に収める(円形・角丸のマスクで縁が切れても不自然にならないようにするため) |
| 背景 | 透明(白背景埋め込みは不可) |
| ファイル名 | `item01.png` 〜 `item24.png`(下表のIDと対応) |
| タッチ・塗り | 24種類で線の太さ・彩度・光の当たり方をできるだけ揃え、ビンゴカードに並んだときに統一感が出るようにしてください |

600×600pxを基準サイズにしている理由は、サイト内で最も大きく使われる箇所
(ガチャ獲得画面・SNSシェア画像生成)で拡大表示されても粗く見えないための
余裕を持たせているためです。実際の表示はすべてこのマスター画像を
CSS/Canvasで縮小して使うので、このサイズより小さいものを送っていただくと
一部の画面でぼやける可能性があります。

## 実際の表示サイズ(参考)

同じ画像がサイズ違いで複数箇所に使われます。仕上がり確認の参考にしてください。

| 使用箇所 | 表示サイズ(目安) |
|---|---|
| ガチャ獲得演出画面のアイコン | 150 × 150px(円形) |
| ビンゴカード(コレクション画面)の1マス内アイコン | 約46〜51px角(画面幅により変動、円形ではなく正方形の中に収まる) |
| SNSシェア用画像(Canvas生成・保存/Xシェア) | 280 × 280px(円形) |
| ビンゴカード保存画像(Canvas生成) | 約120 × 120px角 |
